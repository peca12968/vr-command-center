# 操作員精確觀戰鏡頭

在「觀戰與任務回放」選取錄製場次，開始即時觀戰或回放後，可在「精確調整觀看位置與角度」直接輸入數值。它控制操作員自己的畫面，不移動玩家，不占玩家席位。觀看及保存書籤仍依登入身分與場次房間範圍授權。

| 控制 | 單位／意義 |
|---|---|
| 看向 X／Y／Z | 公尺，畫面中心的全館世界座標，各在 ±120 內 |
| 水平角 | 度，-180 至 180；0 從負 Z 方向觀看，90 從正 X 方向觀看 |
| 俯視角 | 度，約 4.057 至 86.562；越大越接近正上方 |
| 距離 | 鏡頭到看向中心的距離，2–240 公尺 |
| 讀取目前鏡頭 | 將拖曳、跟隨或書籤切換後的目前位置讀入欄位 |
| 套用位置與角度 | 立即切至輸入的自由鏡頭；欄位內按 Enter 也可套用 |

房間 1–5 的中心 X 分別為 -28、-14、0、14、28，地面 Y=0。例如觀看房間 1：看向 (-28,1.25,0.4)、水平角45°、俯視角45°、距離12m，鏡頭位置約為 (-22,9.7353,-5.6)。欄位是看向中心，並非相機本身座標。

即時快照、回放及書籤的背景讀取不覆蓋輸入中的草稿。套用不會自動保存；需要日後切換時，於下方輸入位置名稱並「保存目前位置」。跟隨時讀取／保存的是當下固定視角。切換書籤不會改寫未套用草稿，若想繼續修改該書籤的視角，先按「讀取目前鏡頭」。登出或換錄製場次會清空草稿；讀取新場資料後才啟用輸入。空白、超出範圍或非有限數值不改動畫面。

原操作保持：左鍵拖曳旋轉，Shift 或右鍵拖曳平移，滾輪縮放；聚焦場景後方向鍵平移、+／- 縮放。可隨時切全景、俯視、房間、角色跟隨，或切回保存的位置。視角只是觀察設定，不修改任務、環境、戰鬥及統計。

## 驗證與限制

共用瀏覽器檢查與 `check-operator-native.cjs` 使用真正 pointer／wheel／鍵盤事件及可見表單，不注入場景物件或玩家姿態；核對實際 rendered camera、錯誤輸入、草稿、無管理寫入、書籤與回放。後者啟動方式見 [DESKTOP_CONTROL.md](DESKTOP_CONTROL.md)，使用自己的臨時憑證與真正 Windows server／client 及 Simulation 世界來源。
