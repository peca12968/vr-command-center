# 3D 模擬回放 v0.8

在 `/console/` 登入後開啟「3D 模擬回放」，選擇「載入幾何模擬範例」或匯入新的 schema 2 模擬紀錄。介面以實際快照與已記錄的射線還原簡化場景，不重新執行 AI。此版本驗證無頭盔模擬；尚無 Unity／頭盔任務錄製、即時觀戰或正式場館回放服務。

## 操作

- 播放／暫停，支援 0.25、0.5、1、2、4 倍速；時間軸可跳轉，上一格／下一格可到達同一 tick 內的不同快照。
- 拖曳旋轉鏡頭，Shift 或右鍵拖曳平移，滾輪縮放；方向鍵可平移，`+`／`-` 可縮放。
- 鏡頭可切斜角全景、上帝俯視、跟隨選取角色；房間選單可移到指定房間。點選角色或選單可查看血量、位置與玩家彈匣。
- 綠色角色為玩家、紅色為敵軍；死亡角色淡出。場景物件使用與模擬碰撞相同的盒尺寸及旋轉。黃色為玩家射線，紅色為敵軍射線，顯示最近 0.3 秒的記錄。
- 「此刻統計」按快照的世界事件邊界計算，包含彈藥、擊殺、耗損、中彈、命中率與血量；不是全程固定顯示結束報表。

匯入只在本頁處理，沒有檔案上傳。登出會清除回放與場景，延遲抵達的讀取結果不能恢復舊資料。自行匯入的本機檔案由操作者保管；此功能不提供向 API 跨房讀取錄影的途徑。

## 範例來源與產生

`src/VrCommand.Api/wwwroot/console/examples/simulation.json` 是共用核心實際執行後的合成示範，保留 Simulation 標記，沒有控制台憑證或真實玩家資料。包含 216 份快照、8 筆世界事件及 10.4 秒邏輯時間：低槍口被油桶擋住、AI 命中、玩家側移並擊殺，之後另一個敵軍巡邏繞障。

以 `SIMULATION.md` 的隔離建置步驟建置後，可在空閒房產生另一份紀錄：

```powershell
dotnet artifacts/build-v08/bin/VrCommand.SimulationDemo/release/VrCommand.SimulationDemo.dll --room 5 --output F:/Projects/vr-command-center/artifacts/simulation-demo/my-recording.json
```

工具會結束自己建立的場次、保留統計並輸出 JSON；不結束其他場次。檔案可直接匯入回放頁。邏輯時間依固定 tick 計算，示範程序加速執行，沒有真人遊玩的停頓時長或即時網路時間量測。

## 紀錄與一致性

目前只接受 `schemaVersion: 2`、`rulesVersion: 0.8.0`、`origin: Simulation`，含房間、任務、實際 world props、快照、世界事件與結束統計。舊 schema 1 除錯檔保留，需重跑示範產生新版，不默默猜測缺少的射線。

快照增加行為、自動攻擊、能見度與夜間狀態；射擊事件保存槍口、單位方向、最近碰撞距離、類別與目標 ID。播放直接讀取這些結果，無需重算 AI 或碰撞。快照可有相同 tick，`throughSequence` 決定已套用哪些事件；手動逐格保留每份狀態，連續播放取該時刻最後一份快照。

匯入驗證包含：完整準備／結束、有限座標、角色房間與人數、連續事件序號與唯一 ID、射擊／命中／擊殺因果及冷卻、AI 傷害對應射線、快照血量／彈藥與事件、最後統計一致。資料不一致會拒絕，先前有效回放仍保留。此檢查證明檔案內部一致性，沒有對檔案來源做數位簽章驗證。

原型限制為檔案 25 MiB、20000 份快照、100000 筆事件，每份快照最多 25 個玩家及 100 個敵軍。不是完整長任務的大型錄影格式；後續需持久化分塊、索引、資產版本、校正版本與正式權限下載。玩家目前只有位置及武器方向，尚無頭盔完整六軸姿態、左右手、動畫、MR 或硬體訊號。此版本也沒有回放聲音、影片輸出、鏡頭書籤或即時世界串流。

## 驗證與相依

瀏覽器使用本機提供的 Three.js 0.186.1，MIT 授權與下載來源／SHA-512 位於 `wwwroot/console/vendor/three/`，沒有 CDN 執行相依；原始檔未修改。API CSP 沿用同源資產政策。來源：[Three.js 官方文件](https://threejs.org/docs/)、[原始套件](https://registry.npmjs.org/three/0.186.1)。

`pnpm --dir tests/browser test` 會先執行 12 項回放資料測試，再執行 59 項真實瀏覽器檢查（含 v0.9 管理重試）。瀏覽器檢查以 Chromium SwiftShader 軟體 WebGL 渲染，包含幾何場景、射線、逐格／時間軸／倍速／暫停、自由／跟隨／俯視鏡頭、手機寬度、錯誤檔、未信任文字及登出競態；這不代表實際 GPU 或頭盔效能。已檢視桌面與手機截圖，位於 `artifacts/console/replay-combat.png` 及 `replay-mobile.png`。

搭配本機 295 項核心、302 項 HTTP 斷言與 .NET Standard 建置，驗證的是這套合成記錄的產生、讀取、渲染與統計。完整長期需求中的 Unity、實機任務、25 台連線、持久回放與即時上帝視角仍待整合與驗收。
