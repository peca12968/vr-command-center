# 場館主控台 v0.8

瀏覽器介面與管理 API 由同一個 ASP.NET Core 程序提供，無需額外前端伺服器、雲端服務或瀏覽器外部素材。啟動後開啟 **http://127.0.0.1:5080/console/**。

```powershell
.\scripts\start-local.ps1
```

在本機的 `data/operator-keys.local.json` 找到對應控制台憑證，將單一 Master 或 Room1–Room5 值填入登入欄位。請保管整份檔案，頭盔只使用玩家連線檔。登入欄位會清空，憑證僅保留於該頁記憶體，不寫入 localStorage、sessionStorage、cookie 或 URL；登出／重新載入需重新登入。沒有員工個人帳號登入。

靜態介面可以匿名載入，但每次資料與操作均須 API Bearer 驗證；顯示按鈕不是授權邊界。主控看五房、建立獨立／Linked 場次並編輯任務；房間控制台限自房，包含該房的 Linked 場次可讀但整場命令禁用，只能管理自己的玩家。GameServer 憑證不接受為操作員登入。完整後端規則見 `AUTHORIZATION.md`。

## 操作流程

1. 在「任務庫與編輯」填寫名稱、任務內容、時間（秒）、初始環境及敵軍設定。
2. 加入沙包／油桶，在上視圖拖曳，以 0.5 公尺格點移動；也可選取後用方向鍵，或在右側輸入 X／Y／Z、水平旋轉與素材代碼。圖面顯示 X／Z 的 ±10 公尺範圍；匯入任務的範圍外物件仍保留並可從下拉選單編輯座標。形狀僅供配置示意，沒有尺寸、碰撞或實體場館校正。
3. 「儲存為新任務」建立獨立任務 ID；載入已存任務可再次編輯並另存。沒有覆寫、版本鏈、刪除或復原功能。草稿未持久化，關閉頁面前需儲存。
4. 回到「房間與場次」，選取任務及空閒房間；Linked 必須五房均空閒且為主控。建立後為 Preparing，名冊至少一人才能開始，不代表裝置已就緒。
5. 加入玩家，填入遊戲伺服器的 LAN 地址與埠，點該玩家的「下載連線檔」。檔案只含 Client 角色、地址、埠、五分鐘票券；每台頭盔使用自己的檔案，部署見 `QUEST3.md`。此下載不會建置 APK 或啟動遊戲伺服器。
6. 開始、暫停、繼續或結束場次；也可套用場次環境與敵軍設定。頁面每兩秒更新可見狀態、名冊、統計與最近 20 筆事件，不取代即時 3D 觀戰。
7. 勾選「包含已結束紀錄」查看歷史與統計。統計明確標記模擬／遊戲伺服器來源；沒有戰鬥事件時顯示零值。

## 重試與多人操作

控制命令凍結命令 ID、內容及預期序號後送出。網路錯誤或伺服器 5xx 造成結果不明時，保留「重試確認結果」，鎖定後續寫入及切換場次；重試沿用同一內容，後端去重。此期間停止背景刷新，避免 End 已接受卻因活動列表移除而藏住重試入口。結果確認後再更新列表。關閉頁面仍會失去記憶體中的待確認命令，因此出現待確認提示時應先重試。

環境／敵軍表單保存載入時序號，其他控制台或戰鬥報告推進序號後，舊表單可能回傳 409。先重新整理並按「載入目前設定」後再編輯，避免舊設定覆寫他人變更。背景刷新不會覆蓋輸入中的表單；本頁成功命令或名冊操作後會重新載入設定。

建立場次、加入／移除名冊尚無客戶端去重 ID，不自動重試。若結果不明，先重新整理確認實際名冊與房間再操作。票券重配會產生新票券，不代表舊票券立即失效。

## 驗證

Node 24、pnpm 11.25.0；瀏覽器測試套件鎖定於 `tests/browser/pnpm-lock.yaml`。`pnpm-workspace.yaml` 使用 `nodeLinker: hoisted`，避免 exFAT 的符號連結限制。pnpm 11 的此設定放在 workspace 檔，參考 [官方設定說明](https://github.com/pnpm/pnpm/blob/main/pnpm/docs/settings.md)。

```powershell
pnpm --dir tests/browser install --frozen-lockfile
pnpm --dir tests/browser exec playwright install chromium
pnpm --dir tests/browser test
```

先完成 README 的 .NET Release 建置。測試使用自己的隨機憑證、臨時 API、SQLite 與任務目錄；結束清理子程序及臨時資料，不操作真實開發名冊。Linux CI 安裝瀏覽器時另加 `--with-deps`。

本機 **50 項 Chromium 檢查通過**，涵蓋既有管理流程與新增 3D 模擬回放；另有 12 項回放資料檢查，命令會一併執行。回放包含自由／俯視／跟隨鏡頭、射線、逐格與時間跳轉、倍速／暫停、統計核對、檔案拒絕及登出競態，見 `REPLAY.md`。截圖與檢查摘要在忽略的 `artifacts/console/`，已檢視桌面與手機寬度畫面。本機以隔離的 `artifacts/browser-hoisted` 提供 Playwright 1.62.1，CI 使用一般安裝路徑；雲端 CI 仍受既有帳戶付款／支出限制影響，尚無通過證據。

## 尚未接入

新增「3D 模擬回放」可讀取共用核心產生的紀錄，提供自由鏡頭與播放控制，見 `REPLAY.md`。沒有即時戰鬥串流或頭盔任務錄製。配置尚未套用到 Unity 場景，控制台敵軍按鈕尚未持續驅動遊戲世界；Unity、天氣／MR／硬體及 25 台裝置效能仍須各自驗收。

服務預設僅在本機。若需讓其他控制電腦連入，須先完成 TLS、個人帳號／傳輸保護與部署限制。靜態檔案中介層與公開介面／受保護 API 的安排參考 [ASP.NET Core static files](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/static-files?view=aspnetcore-10.0)；不開啟目錄瀏覽。
