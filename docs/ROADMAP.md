## 下一個開發順序

1. M0 本機與推送已驗證；待 GitHub 帳戶付款／支出限制解除後執行雲端 CI，期間持續開發 M1。
2. 優先完成 Quest 3 工程的實際 Prepare、EditMode、桌面及 APK 建置；SDK 條款已確認、原生工具已驗證，需完成工具端實際可讀的 Unity 登入／授權，再驗雙玩家互見，見 `QUEST3.md`。
3. 將已通過 .NET 驗證的射擊／掩體／AI 核心接入 Unity 的真實玩家輸入與任務，再量測同步與效能；無頭盔示範維持 Simulation，加入持久世界快照及 3D 觀戰回放。
4. 建立／加入／離開的客戶端去重已完成；伴隨整合補齊裝置重連、每次入場票券撤銷版本，以及廠商硬體模擬與正式轉接器。

管理介面位於 `/console/`，見 `CONSOLE.md`；核心與回放見 `SIMULATION.md`／`REPLAY.md`。v0.9 本機通過 213 項核心、282 項 HTTP、12 項回放資料及 56 項 Chromium 檢查，含 3D 模擬回放與持久生命週期去重；不代表 Unity、頭盔、25 台效能、正式持久回放或即時觀戰驗收。

不先承諾日程與成本；取得團隊規模、素材來源、頭盔型號、場地與協議後才能估算。每次交付更新 `PROGRESS.md`，有可驗證成果再更新本表。
