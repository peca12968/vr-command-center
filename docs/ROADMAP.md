## 下一個開發順序

1. M0 本機與推送已驗證；待 GitHub 帳戶付款／支出限制解除後執行雲端 CI，期間持續開發 M1。
2. 優先完成 Quest 3 工程的實際 Prepare、EditMode、桌面及 APK 建置；先處理 Unity 登入／授權與 Android 模組條款，再驗雙玩家互見，細節見 `QUEST3.md`。
3. 戰鬥統計與模擬來源已驗證；後續以權威射擊／碰撞／AI 替換模擬來源，加入世界快照及 3D 觀戰回放。
4. 伴隨整合補齊建立／加入／離開的客戶端去重、裝置重連，以及廠商硬體模擬與正式轉接器。

目前可直接操作的管理介面位於 `/console/`，見 `CONSOLE.md`。v0.6 本機通過 128 項核心、229 項 HTTP 及 36 項 Chromium 檢查；這些不是頭盔、25 人效能或 AI／3D 回放驗收。

不先承諾日程與成本；取得團隊規模、素材來源、頭盔型號、場地與協議後才能估算。每次交付更新 `PROGRESS.md`，有可驗證成果再更新本表。
