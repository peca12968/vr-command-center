## 下一個開發順序

1. 完成 M0，將驗證結果寫入進度，推送並確認 GitHub CI。
2. 實作場次生命週期與操作員命令／事件契約，作為即時控制與回放共用基礎。
3. 實作可去重的戰鬥事件及統計投影，使用模擬器驗證，保留實機驗收標記。
4. 建立遊戲端與硬體端模擬接入；再整合 Unity 與廠商 SDK。

不先承諾日程與成本；取得團隊規模、素材來源、頭盔型號、場地與協議後才能估算。每次交付更新 `PROGRESS.md`，有可驗證成果再更新本表。
