## 下一個開發順序

1. M0 本機與推送已驗證；GitHub 曾實際執行部分檢查，最新仍受帳務限制，待可執行後驗證完整雲端結果，期間推進遊戲接入。
2. 優先完成 Quest 3 工程的實際 Prepare、EditMode、桌面及 APK 建置；SDK 條款已確認、原生工具已驗證，需完成工具端實際可讀的 Unity 登入／授權，再驗雙玩家互見，見 `QUEST3.md`。
3. Unity 已有共用核心、任務／輸入／同步及 HUD 接入來源碼，優先真正編譯運行；outbox、Pause／End 補送及封存已通過跨程序驗證，接續建立世界快照及 3D 即時觀戰。無頭盔示範維持 Simulation。
4. 建立／加入／離開的客戶端去重已完成；伴隨整合補齊裝置重連、每次入場票券撤銷版本，以及廠商硬體模擬與正式轉接器。

管理介面位於 `/console/`，v0.11 新增持久事件、補送及完整性提示，見 GAMEPLAY／TELEMETRY。本機通過 295 項核心、302 項 HTTP、12 項回放資料及 59 項 Chromium 檢查；16 份 C# 語法通過仍不代表 Unity、頭盔、25 台效能、正式持久回放或即時觀戰驗收。

不先承諾日程與成本；取得團隊規模、素材來源、頭盔型號、場地與協議後才能估算。每次交付更新 `PROGRESS.md`，有可驗證成果再更新本表。
